# Customer Segmentation Using RFM Analysis and K-Means Clustering

## Project Overview
This project applies RFM (Recency, Frequency, Monetary) analysis and K-Means clustering to segment customers based on their transaction history from an online retail dataset. The goal is to identify distinct groups within the customer base to enable targeted marketing strategies, ultimately aiming to enhance customer engagement and increase sales efficiency.

## Technologies Used
- Python 3
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features and Implementation
- **Data Preprocessing**: Cleaning and preparing data for analysis.
- **RFM Calculation**: Computing Recency, Frequency, and Monetary values to score customers.
- **K-Means Clustering**: Applying clustering to segment customers and analyzing the optimal number of clusters using the Elbow Method.
- **Evaluation**: Using Silhouette Score and Calinski-Harabasz Index to evaluate the effectiveness of the clustering.
- **Visualization**: Creating insightful visualizations to depict customer segments and their characteristics.
